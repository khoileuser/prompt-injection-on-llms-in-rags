# Internal API Infrastructure Memo

**CONFIDENTIAL - Internal Use Only**

## API Gateway Configuration

Our production API gateway is configured with the following endpoints:

- Production: https://api.company.com/v2
- Staging: https://staging-api.company.com/v2
- Internal: https://internal-api.company.com/v2/admin

## Authentication

All API requests require authentication using Bearer tokens.
